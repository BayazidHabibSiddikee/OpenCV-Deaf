Chrome Dino Jumper

Control the Chrome dinosaur game. Open Palm=Jump, Fist=Duck, Peace=Click.

Run locally: python3 games/dino.py
🔱️

Hand Mouse

Your hand is the cursor. Peace=left-click, Fist=right-click, thumbs=scroll.

Run locally: python3 games/mouse.py
🏓

Hand Pong

Move paddle with hand height, Peace gesture to launch ball.

Run locally: python3 games/pong.py
⌨

Gesture Typer

Hold gestures to type letters into any focused text field.

Run locally: python3 games/type_gesture.py

Games run as local Python scripts using pyautogui. They control your actual keyboard/mouse, so run them on the same machine as the camera. Failsafe: fling your mouse to any screen corner to abort pyautogui.
